# PortSwigger Web Security Labs

Notes and practical exercises from [PortSwigger Web Security Academy](https://portswigger.net/web-security), following the [Server-side vulnerabilities — Apprentice learning path](https://portswigger.net/web-security/learning-paths/server-side-vulnerabilities-apprentice).

## Repository Structure

Labs are organized by vulnerability category, with individual directories for each lab.

Each lab contains:

- `notes.md` — Concise explanations, key concepts, and technical examples.
- `images/` — Screenshots documenting requests, testing steps, and results.

## Disclaimer

All testing is performed in authorized lab environments for educational purposes.
